## 📖 **About Wander World**  
Wander World is a **React-based web application** designed for **explorers and travel enthusiasts**.  
Users can **view detailed country information**, **save favorite countries**, and **personalize their experience**.  

### ✨ **Features**
✅ **Interactive Country Explorer** – View country details, maps, populations, languages & more!  
✅ **Save Favorites** – Keep track of favorite countries & manage them easily.  
✅ **Secure Authentication** – User-based country preferences via Firebase authentication.  
✅ **Smooth UI & Animations** – Elegant design with Framer Motion for enhanced experience.  
✅ **Persistent Local Storage** – Favorites are stored per user for seamless access.
